## Project at a glance

- **Stack:** Next.js 16.3.4, React 19.2.8, TypeScript 5 (strict), Tailwind CSS v4.
- **Package manager:** npm (`package-lock.json`). Do not introduce yarn/pnpm lockfiles.
- **Router:** App Router; entrypoint is `app/layout.tsx`, home page is `app/page.tsx`.
- **No CI, no tests, no pre-commit hooks.** Do not assume a test runner exists.

## Common commands

- `npm install` — install dependencies.
- `npm run dev` — start dev server on http://localhost:3000.
- `npm run build` — production build.
- `npm run lint` — run ESLint (`eslint.config.mjs`, flat config).
- `npx tsc --noEmit` — typecheck; there is no dedicated `typecheck` script.

## Tailwind CSS v4 specifics

- Config lives in `postcss.config.mjs` (`@tailwindcss/postcss`), **not** a `tailwind.config.js`.
- Theme tokens are defined in `app/globals.css` via `@import "tailwindcss"` and `@theme inline`.
- Fonts are loaded with `next/font/google` (`Geist`, `Geist_Mono`) and exposed as CSS variables (`--font-geist-sans`, `--font-geist-mono`).

## Module paths and generated files

- Path alias `@/*` maps to the repo root (`./*`).
- `next-env.d.ts` is generated by Next.js; do not edit it.
- `.next/` and `out/` are build outputs; `.playwright-mcp/*` is gitignored and reserved for Playwright MCP artifacts.
